Training runs, May 2026 to now

Not directly comparable across erasRuns before v3 were only ever scored on their own validation sets (5 to 26 images), which differ by campaign. From v3 on, the headline numbers are from the held-out test set.
"Multilayer" means two different thingsUntil July it was a class the model predicted (the outer outline only). Since July the model finds every membrane layer as one EV class, and a detection that contains others is counted as multilayer afterwards (containment).
How runs are scoredDetections are matched one-to-one to labels at mask IoU ≥ 0.5, conf ≥ 0.25 (the May sanity runs used 0.35 / 0.30). F1 combines precision and recall. Mask IoU is the average overlap of matched detections with their labels, i.e. how well the outlines fit.
CoverageThis page only gathers numbers already saved on disk; nothing was re-run. Multilayer and inner-layer scores exist only for the five runs that had a containment analysis. Re-scoring every run the same way is the next step.
